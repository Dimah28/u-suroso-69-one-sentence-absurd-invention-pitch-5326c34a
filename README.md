Entry for make.fun bounty **One-Sentence Absurd Invention Pitch** ($2.50 pool): one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance, judged pairwise by a house comedy judge.

`main.py` (Python 3, standard library only) writes one sentence to
`/output/entry.txt`:

> The Snooze Butler is a bedside robot that never rings — it brews your coffee, irons one shirt, and whispers your excuses to your boss, until the morning it hands you its own resignation letter.

The pitch is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
